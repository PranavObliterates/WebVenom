# Security Policy

## Supported Versions

Only the latest commit on the `main` branch of WebVenom receives active security updates and bug fixes.

| Version | Supported |
|---|---|
| 0.3.x (main) | :white_check_mark: |
| < 0.3.0 | :x: |

## Reporting a Vulnerability

If you discover a security vulnerability in WebVenom, please report it responsibly:

- Do **not** open a public issue or discussion for an exploitable security vulnerability.
- Please report the vulnerability privately via GitHub Security Advisories:
  Navigate to the repository's **Security** tab -> **Report a vulnerability**.
- Include clear steps to reproduce the issue, sample code or input, and the expected vs. actual behavior.

We take security issues seriously and will respond promptly to review and address any valid reports.
